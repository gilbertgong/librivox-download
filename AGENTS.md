# Instructions for AI assistants

Before doing anything in this repo, read these files and follow them:

1. `AI/MEMORY.md`: how to work here (the user's preferences and rules).
2. `AI/PROJECT_LOG.md`: the project (goal, decisions and their reasons, how things work, status, open questions).
3. `AI/LOCAL.md`, if it exists: this computer only (local paths, related projects, local run state). It isn't in
   version control, so a fresh clone has none.

`AI/STRATEGY.md` explains how the repo is organized for AI assistants, and how to set the same up elsewhere.
